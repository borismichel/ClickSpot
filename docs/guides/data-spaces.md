# Working with Data Spaces

A [Data Space](../concepts/data-spaces.md) is a scoped view over the warehouse with its own
chat, dashboards, and filters. This guide covers creating one and working inside it.

## Create a Data Space

From the Data Spaces list, create a new space and give it a name and scope. The designer is
where you configure what the space covers — the objects, filters, and defaults that define
the slice.

## Work inside a space

Once a space is set up, it behaves like a focused copy of ClickSpot:

- **Chat** answers questions within the space's scope.
- **Dashboards** belong to the space and respect its filters.
- **Filters** (date, owner, pipeline) define the slice and apply throughout.

Switch between the full warehouse and any space from the app navigation.
