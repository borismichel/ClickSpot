# ClickSpot — Frontend

React 19 + TypeScript + Vite single-page app. Chat, dashboards, data spaces, data explorer.

## Run

```bash
npm install
npm run dev   # http://localhost:8193 — proxies /api to backend at :8192
npm run build # outputs to dist/
```
